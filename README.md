# Web Technology Practice

A comprehensive hands-on repository for learning Web Technology
and the MERN Stack from fundamentals to advanced concepts.

## Technologies

- HTML5 and CSS3
- JavaScript (ES6+)
- React
- Node.js and Express.js
- MongoDB and Mongoose
- Git and GitHub
- REST APIs, testing, and deployment

## Learning Method

Concepts -> Examples -> Practice -> Mini Projects -> Full-Stack Projects

## Repository Structure

Each numbered directory represents a learning area.
Code examples and exercises will be added progressively.

## Practice Rules

- Write and run the code yourself.
- Keep examples small and focused.
- Document important concepts and common errors.
- Build projects after completing related concepts.
- Never commit passwords, API keys, or real .env files.
